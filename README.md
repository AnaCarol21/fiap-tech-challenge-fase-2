# 📚 Tech Challenge - Fase 2

## Pipeline Híbrido para Análise da Alfabetização no Brasil

Projeto desenvolvido para o Tech Challenge da Pós-Tech FIAP, com o objetivo de construir uma pipeline híbrida de dados (Batch + Streaming) para integração, tratamento e disponibilização de dados públicos sobre alfabetização infantil no Brasil.

---

## Objetivo

Construir uma arquitetura de dados escalável em nuvem seguindo o padrão da **Arquitetura Medalhão (Bronze, Silver e Gold)**, utilizando dados da **Base dos Dados**, permitindo análises sobre o Indicador Criança Alfabetizada.

---

## Arquitetura (em desenvolvimento)

- 🔹 Batch: Base dos Dados
- 🔹 Streaming: Apache Kafka
- 🔹 Data Lake: Amazon S3
- 🔹 Camadas Bronze, Silver e Gold

---

## Tecnologias

- Python
- Google Colab
- Apache Kafka
- Amazon S3
- PySpark
- Base dos Dados
